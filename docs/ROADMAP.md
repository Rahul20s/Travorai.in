# 12-Week Roadmap

## Weeks 1-2: Foundation

- Finish Next.js platform structure.
- Add Clerk authentication.
- Connect Supabase PostgreSQL through Prisma.
- Implement saved trips and user travel profile.
- Add PostHog and Sentry basics.

## Weeks 3-4: AI Planner MVP

- Add Vercel AI SDK structured output.
- Build planner, budget, weather and packing agents.
- Store conversations and messages.
- Render trip timeline, cards and expense summary from JSON.

## Weeks 5-6: Travel Experience

- Add Mapbox maps.
- Add OpenWeather timeline.
- Add mock hotel, train, flight and activity adapters.
- Add shareable public trip pages.

## Weeks 7-8: User Value Loops

- Add packing checklist.
- Add expense tracker.
- Add saved places and wishlist.
- Add trip reminders and weather alerts.

## Weeks 9-10: Monetization Prep

- Add affiliate link tracking.
- Add referral codes.
- Add premium plan gating.
- Add Razorpay and Stripe skeletons.

## Weeks 11-12: Launch Readiness

- Add admin dashboard.
- Add AI usage cost logging.
- Add feedback collection.
- Add SEO pages for popular destinations.
- Run beta with first 20-50 users.
